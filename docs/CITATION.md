# Citing OpenVolley

If **OpenVolley** contributes to your academic paper, undergraduate/graduate thesis, sports informatics study, or technical publication, please cite it using one of the standard formats below.

GitHub also exposes an interactive **"Cite this repository"** widget in the repository sidebar powered directly by [`CITATION.cff`](../CITATION.cff).

## BibTeX

  author       = {Ryan, Ardian},
  title        = {{OpenVolley: A Self-Hosted Real-Time Volleyball Scoreboard, Symmetric Tournament Bracket, and Client-Side Broadcast Media Suite}},
  version      = {0.1.0},
  year         = {2026},
  month        = nov,

}
